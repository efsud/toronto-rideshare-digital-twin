# Task Artifacts

Visual and validation outputs from incremental development tasks.

Each subfolder follows the naming convention:

```text
artifacts/task_XX_short_description/
```

Contents are generated locally. Large binary outputs remain git-ignored except README stubs.

## Index

| Folder | Task | Description |
|--------|------|-------------|
| `task_00_env/` | 00 | Environment validation report |
